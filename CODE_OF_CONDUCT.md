# Code of Conduct

## Our standards

The IMSYP Auto Reader project welcomes constructive participation from contributors, users, reviewers, and maintainers.

Expected behavior includes:

- communicating respectfully and professionally;
- giving technical feedback based on evidence and reproducible results;
- respecting differences in experience, background, and viewpoint;
- keeping discussions focused on the project and its users;
- protecting private, confidential, and security-sensitive information.

Unacceptable behavior includes harassment, threats, discrimination, personal attacks, deliberate disruption, publishing private information without permission, or other conduct that makes project participation unsafe or hostile.

## Scope

This code applies to project spaces, including issues, pull requests, discussions, reviews, and other public interactions made on behalf of the project.

## Enforcement

Project maintainers may edit, hide, reject, or remove contributions or comments that violate these standards and may restrict participation when necessary.

Security vulnerabilities should not be disclosed publicly before a fix is available. Please follow `SECURITY.md` for security reporting.

## Contact

For conduct concerns related to this project, contact the project owner through the official IMSYP project channels.
